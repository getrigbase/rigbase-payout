Over-cap payout: what happens

The session can spend at most 15 USD₮ per week. On the agent was asked to pay , more than the cap allows.

refused

Two layers: a local 7-day ledger refuses first. With --probe-cap the agent asks the Altana relay to simulate it anyway, and the account's on-chain spend limit rejects it. Over-cap intents are never broadcast. Try it yourself with npm run pay -- run payroll/demo-over-cap.json (dry run, no key needed beyond a read-only wallet file).
